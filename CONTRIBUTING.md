# Contributing

## Backlog hygiene

Every GitHub issue and story in this repository must include these five sections, so that
anyone picking it up knows exactly what to build, how it will be judged, and where its edges
are. An issue that is missing any of them is not ready to work.

- **Context** — why this work exists: the problem, the trigger, and any background a reader
  needs.
- **Acceptance criteria** — the concrete, checkable conditions that mean the work is done.
- **Tests** — how the change is verified (the checks, cases, or validation to add or run).
- **Out of scope** — what this issue deliberately does not cover, to keep it focused.
- **Dependencies** — other issues, PRs, or work this one relies on or blocks (write "None" if
  there are none).

Copy this template into a new issue and fill in each section:

```markdown
## Context


## Acceptance criteria


## Tests


## Out of scope


## Dependencies

```
